# All Apps

**Live:** https://mrbugimposter3-ship-it.github.io/all-apps/

All of Rafeh's live GitHub Pages apps in one launcher, for families and Quran learners. Each app opens full-screen; switch with the tab bar, the ‹ › buttons, a swipe on the bottom bar or the screen edges, or the arrow keys.

## Features
- **33 apps** in one place, with a scrollable tab bar (deep links work: `…/all-apps/#juz-daily`).
- **Swipe to switch** on the bottom bar or the thin left/right screen edges, so swipes inside the apps still work.
- **Auto-switch timer**, aligned to the clock: by default it moves to the next app at :00, :10, :20, :30, :40 and :50. It shows a countdown, has a pause/resume button, and the interval (1–60 min) can be changed in Settings.
- **Keep screen on** (Wake Lock API; in the Android app it uses FLAG_KEEP_SCREEN_ON).
- **Lazy loading:** an app loads only when you open it, and the last 4 visited (adjustable) stay alive so they keep their place.
- **Fallback:** if an app won't load inside the launcher, an "Open in new tab" button appears. ↗ is always in the toolbar.
- Choose which apps are in the rotation. All settings are saved on the device (localStorage).
- Built for iPhone, Android phones and iPad (portrait and landscape), with safe-area support. You can add it to the Home Screen.

## الإنفاق في سبيل الله: spending in the cause of Allah
The Settings panel shows a rotating card of ayat on spending in Allah's cause, zakat and charity: 2:261, 2:274, 9:60, 57:7, 64:16, 3:92, 2:267, 2:245, 2:43, 2:177, 9:103, 63:10, 34:39 and 73:20. The Uthmani text and Pickthall English come from [api.alquran.cloud](https://alquran.cloud/api) (`gen_infaq.py` → `infaq.js`).

## Adding new apps
```
python3 build_apps.py     # needs gh authenticated; rewrites apps.json
git commit -am "Refresh apps" && git push
```
It lists the owner's public repos with GitHub Pages and keeps only those whose Pages URL returns 200. Private repos and `all-apps` itself are skipped. You can rename tabs in `NAMES` in `build_apps.py`.

## Android
`releases/All-Apps.apk` (package `com.knowboran.allapps`) is a WebView of the live site. It has JavaScript, DOM storage and media autoplay, and keeps the screen on. "Open in new tab" opens the system browser. To rebuild, run `./build.sh` (JDK 17 + Android SDK 34, no Gradle).
